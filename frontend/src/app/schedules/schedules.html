Schedules

Manage salary and fixed recurring expenses. Schedule changes inform Forecast only until you execute an eligible occurrence.

How schedules, forecast, and execution work

Forecast counts occurrences from the next occurrence, not from the start date. Creating or editing a schedule does not add a transaction and does not change account balances.

Use Execute occurrence on an active schedule to materialize today’s eligible occurrence as a transaction (server date applies). Choosing an account links the commitment to that account. Use the Forecast page account filter to project that account alone.
