Schedules

Expected future salary and fixed recurring expenses. Forecast counts occurrences from the next occurrence, not from the start date. Creating or editing a schedule does not add a transaction, including when the start date is already in the past, and it does not change account balances. Use Execute occurrence on an active schedule to materialize today's eligible occurrence as a transaction. Choosing an account links the commitment to that account. Use the Forecast page account filter to project that account alone.
